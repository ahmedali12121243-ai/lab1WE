# Ahmed Ali - Personal Portfolio

CS313: Web Engineering — Lab 3: HTML Advanced - Personal Portfolio II

## About

This is my personal portfolio website, built with plain HTML and CSS
(no JavaScript, no CSS frameworks). It extends my Lab 2 portfolio by:

- Moving all styling into a single external stylesheet (`css/style.css`).
- Organizing the project into `css/` and `images/` folders.
- Using **float** and **clear** to lay out the navigation menu, the
  About Me section (photo + wrapped text), and the image gallery.
- Deploying the site with GitHub Pages.

## How to Run Locally

Simply open `index.html` in any modern web browser — no build step or
server is required.

## Deployment (GitHub Pages)

1. Push this folder to a GitHub repository.
2. Go to **Settings → Pages** in the repository.
3. Under **Build and deployment**, set the source branch to `main`
   (root folder) and save.
4. The live site will be available at:
   `https://<your-github-username>.github.io/<repository-name>/`
